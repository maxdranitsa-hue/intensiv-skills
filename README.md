# Скиллы интенсива Claude Code

Набор рабочих скиллов для участников интенсива. Ставятся **одной командой** — дай Claude Code ссылку на этот репозиторий и попроси установить всё.

## Как поставить ВСЕ скиллы сразу

Открой Claude Code (в VS Code или терминале) и вставь:

```
Установи мне все скиллы из репозитория https://github.com/maxdranitsa-hue/intensiv-skills
Скачай его и скопируй каждую папку из папки skills/ ко мне в скиллы:
на Mac — в ~/.claude/skills/, на Windows — в %USERPROFILE%\.claude\skills\
Потом покажи список, что установилось.
```

Claude всё скачает и разложит сам. После этого перезапусти Claude Code — скиллы появятся.

## Что внутри

| Скилл | Что делает |
|---|---|
| **skill-check** | Проверяет любой скачанный скилл на безопасность перед установкой (Cisco AI Skill Scanner, Windows + Mac). |
| **second-brain-setup** | Переезд второго мозга на сервер VPS: бот 24/7 + синхра заметок. |
| **meeting-review** | Разбор транскрипта встречи/звонка → отчёт с задачами. |
| **commercial-offer** | Коммерческое предложение / расчёт по входящей заявке клиента. |
| **session-handoff** | Сворачивает длинную сессию в резюме, чтобы продолжить работу без потери нити. |

## Безопасность

Скиллы из ЧУЖИХ источников всегда проверяй перед установкой:
```
Проверь скилл <путь-к-папке> через skill-check
```
Ставь только после «зелёного света».
